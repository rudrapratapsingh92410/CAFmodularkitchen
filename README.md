## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Steps
```bash
# Navigate to project directory
cd caf-modular-kitchen

# Install dependencies (already installed)
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

The application is built using **Vite 6/8**, **React 19**, and **Tailwind CSS v4** with **Lucide React**.

---

## 📦 Deployment Instructions

The production build is located in `caf-modular-kitchen/dist/`. It is 100% static and can be deployed anywhere in seconds:

- **Vercel / Netlify / Cloudflare Pages:** Connect repository or run `npx vercel` / `netlify deploy --prod --dir=dist`.
- **Traditional Apache/Nginx Web Server:** Upload the contents of `dist/` directly to your public web directory (e.g. `public_html`).
